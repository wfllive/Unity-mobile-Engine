# Инструкция по запуску

Всё, что нужно — **Node.js 18+**. JDK, Android SDK и Gradle не требуются даже для сборки APK.

---

## 1. Установка

```bash
git clone https://github.com/wfllive/Unity-mobile-Engine.git
cd Unity-mobile-Engine
git checkout arena/01a01ed8-unity-mobile-engine
npm install
```

## 2. Запуск в браузере

```bash
npm run dev
```

Откройте **http://localhost:3000** — сразу загрузится демо-сцена (паркур-арена, 66 объектов).

Первым делом `npm run dev` собирает рантайм для APK, потом поднимает Vite. Это нормально,
что в логе сначала появляется строка «WFL: рантайм собран».

Сервер слушает `0.0.0.0`, так что с телефона в той же сети можно зайти по адресу
`http://<ip-компьютера>:3000` — включатся виртуальный джойстик и кнопки.

## 3. Управление

**В игре:** `WASD` — движение, мышь — камера, `Пробел` — прыжок, `Shift` — бег, `E` — взаимодействие.
На телефоне — джойстик слева, кнопки справа, свайп по экрану — обзор.

**Горячие клавиши:**

| Клавиша | Действие |
|---|---|
| `F2` | открыть/закрыть редактор сцены |
| `F4` | диалог сборки APK |

Внизу слева на десктопе есть кнопка «⚙ Редактор». Из консоли браузера движок доступен
как `window.wfl` (`wfl.engine`, `wfl.scene`, `wfl.editor()`, `wfl.buildApk()`).

## 4. Редактор сцены (`F2`)

Слева иерархия, справа инспектор, снизу консоль. Хоткеи в стиле Unity:

| Клавиша | Действие |
|---|---|
| `W` / `E` / `R` | перемещение / поворот / масштаб |
| `F` | приблизиться к выбранному |
| `Ctrl+D` | дублировать |
| `Del` или `X` | удалить |
| `Esc` | снять выделение |

Сцена сохраняется в `localStorage`, есть экспорт в JSON и кнопка «📦 Собрать APK».
На узком экране панели превращаются во вкладки.

## 5. Редактор блюпринтов

Выделите объект и нажмите **«🧩 Блюпринт»** в верхней панели (или кнопку «Открыть граф»
в инспекторе компонента `Blueprint`). Если компонента на объекте нет, он добавится сам.

Быстрый старт: нажмите **«Шаблон»** — вставится готовый пример (сообщение при старте
и вращение 90°/с), затем **«Применить»**.

- **«+ Узел»** — палитра с поиском, 74 типа узлов.
- Связи тянутся мышью от пина к пину; клик по связи удаляет её.
- Колесо или щипок — зум, перетаскивание фона — панорама, **«Вписать»** — показать весь граф.
- **«Разложить»** — автоматическая раскладка, **«Проверить»** — валидация графа.

| Клавиша | Действие |
|---|---|
| `Ctrl+A` | выделить все узлы |
| `Ctrl+D` | дублировать выделенные |
| `Del` или `X` | удалить выделенные |
| `F` | вписать граф в экран |
| `Esc` | закрыть редактор (граф применяется) |

Граф сохраняется внутри компонента и переживает сериализацию сцены — то есть работает
и в собранном APK.

## 6. Сборка APK

Из браузера — клавиша `F4`, заполнить поля и скачать файл.

Из командной строки:

```bash
# простейший вариант — демо-сцена внутри
npm run apk -- --name "Моя игра" --package com.studio.game

# со своей сценой, экспортированной из редактора
node tools/cli.mjs apk --scene my.wflscene.json --out build/game.apk

# сведения о готовом файле
node tools/cli.mjs info game.apk
```

Полезные опции: `--portrait` (портретная ориентация), `--version 1.2`, `--version-code 5`,
`--min-sdk 21`, `--debug`, `--key key.pem --cert cert.pem` (своя подпись вместо
автоматически сгенерированной). Полный список — `node tools/cli.mjs help`.

Установка на телефон: `adb install -r game.apk` либо скиньте файл на устройство и
откройте его, разрешив установку из неизвестных источников. APK подписан схемами v1 и v2.

## 7. Прод-сборка сайта

```bash
npm run build     # результат в dist/
npm run preview   # локальный просмотр собранного
```

## 8. Тесты

```bash
npm test          # 9 наборов, в т.ч. 154 проверки блюпринтов
```

Отдельно есть smoke-тест интерфейса редактора блюпринтов — он не входит в `npm test`,
потому что требует необязательную зависимость:

```bash
npm install --no-save jsdom
node tools/test/manual/bp-ui-smoke.mjs
```

## Если что-то не запускается

**`Cannot find package 'esbuild'` / `'vite'`** — не выполнен `npm install`.

**`Port 3000 is already in use`** — порт занят прошлым запуском. Освободите его
(`kill $(lsof -t -i:3000)`) или укажите другой: `npx vite --host 0.0.0.0 --port 3100`.

**Пустой экран, в консоли ошибки WebGL** — нужен браузер с поддержкой WebGL 2
(актуальные Chrome, Firefox, Safari) и включённым аппаратным ускорением.

**Не собирается APK** — проверьте, что рантайм собран: `npm run build:runtime`.
Он создаёт `src/apk/runtime-bundle.js`, которого нет в git.
